# Eight-clone comparison (zero guest RAM divergence), repeat run

This is a second sample of the experiment described in
[`../eight-clone-zero-divergence-run1/README.md`](../eight-clone-zero-divergence-run1/README.md).
It ran on 2026-10-26 with QEMU 11.1.2, Linux 7.2.11, KVM, 4 KiB pages, and
the synthetic initramfs guest. Each VM has 256 MiB configured RAM. The probe
created eight ordinary baseline VMs and eight template clones from the same
generated guest artifacts.

Reproduce with:

```sh
densevm probe --out RUN_DIRECTORY --count 8 --divergence-percent 0
densevm stats RUN_DIRECTORY/result.json
```

## Measurements

| Measurement | Run 1 | Run 2 |
| --- | ---: | ---: |
| Ordinary baseline startup to 8 ready (ms) | 11,221 | 11,520 |
| Template clone startup to 8 resumed (ms) | 3,340 | 2,835 |
| Aggregate ordinary baseline process PSS (KiB) | 1,625,501 | 1,633,637 |
| Aggregate clone process PSS before divergence (KiB) | 462,966 | 461,830 |
| Aggregate clone process PSS after 0% divergence (KiB) | 462,997 | 461,933 |
| Clone PSS plus full template cache bound (KiB) | 725,141 | 722,009 |
| Template RAM file resident at measurement (KiB) | 262,144 | 260,076 |

The baseline PSS differed by about 0.5% between samples; clone PSS differed
by less than 0.3%. These are two samples, not enough to characterize a
distribution. The template RAM file was fully resident in run 1 and about
99.2% resident in run 2. The conservative PSS-plus-cache value double-counts
some mapped pages. Process PSS excludes KVM metadata and host page tables, and
the baseline excludes unmapped disk and kernel file cache. Do not treat these
process measurements as total host memory.

The raw QEMU commands and per-VM measurements are in `result.json`;
`summary.json` is generated by `densevm stats`.
